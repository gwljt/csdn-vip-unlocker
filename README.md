# CSDN VIP 文章解锁器

一个智能、跨平台的 Python 脚本，用于解锁 CSDN VIP 文章，移除遮罩和登录弹窗。基于 `nodriver` 构建，实现隐身浏览器自动化。

## ✨ 核心功能

- **✅ 自动移除 VIP 遮罩 / 关注博主限制**：自动定位并移除 `.hide-article-box`，展开被前端隐藏的全文内容。
    - *注意：本项目原理是还原网页已加载但被遮挡的内容（如“关注博主阅读全文”），并不涉及破解服务器端截断的 VIP 专享文章。所见即所得，无法获取服务器未发送的数据。*
- **✅ 屏蔽登录弹窗**：静默拦截并删除强制登录框、扫码框及背景遮罩。
- **✅ 多标签页支持**：实时监控所有浏览器标签页。自由打开新链接，脚本会自动处理每一个页面。
- **✅ 全平台兼容**：已在 **macOS**, **Windows**, 和 **Linux** 上验证通过。
- **✅ 登录状态持久化**：自动保存 Cookie 到本地 `./browser_data`，重启后无需再次登录。
- **✅ 智能浏览器检测**：内置自动探测逻辑，优先寻找 Chrome/Edge/Brave/Chromium 等浏览器，零配置启动。

## 🐍 为什么选择 Python + Nodriver？ (Why Python?)

相比于常见的浏览器插件 (Tampermonkey/Greasemonkey) 或纯 JavaScript 脚本，本项目采用 Python (`nodriver`) 方案具有显著的技术优势：

1.  **更底层的控制权 (Full Control)**:
    -   直接与浏览器内核 (CDP 协议) 通信，能够拦截并修改**网络请求 (Network Interception)**。这意味着可以在 JS 代码到达浏览器并执行*之前*就对其进行篡改，从根源上破坏反爬逻辑，而不仅仅是事后在 DOM 上修补。
2.  **隐匿性更强 (Stealth)**:
    -   `nodriver` 使用非典型的 WebDriver 启动方式，难以被常规的自动化检测脚本识别 (e.g. `navigator.webdriver` 标记)。行为更像真实用户。
3.  **系统级集成 (System Integration)**:
    -   拥有完整的本地文件系统访问权限，能够轻松实现 Cookie 的持久化存储 (Session Persistence) 和跨会话管理，不受浏览器沙箱限制。
4.  **高可用性 (Stability)**:
    -   作为一个独立的系统进程运行，不会因为页面的刷新、跳转或崩坏而停止工作。能够同时监控管理多个标签页，实现“一处启动，全站通行”。

## 📦 安装指南

1.  **克隆项目**:
    ```bash
    git clone https://github.com/gwljt/csdn-vip-unlocker.git
    cd csdn-vip-unlocker
    ```

2.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```
    *注意：需要先安装基于 Chromium 的浏览器（Chrome, Edge, Brave 等）。*

## 🚀 使用方法

1.  **运行脚本**:
    ```bash
    python main.py
    ```

2.  **开始浏览**:
    - 脚本会自动启动浏览器窗口。
    - 访问任意 CSDN 博客文章。
    - VIP 遮罩和登录弹窗将被自动移除。
    - 你可以随意打开新标签页，脚本会自动后台处理。
